# 🏏 CricketAdda

Modern, live-sync cricket scoring, tournament management, and spectator broadcast application built with React Native and Expo.

## 🚀 Features
- **Live Match Scoring**: Ball-by-ball scoring with undo, wagon wheel tracking, run rates, and projected score matrix.
- **Spectator Mode vs Scorer Mode**: Secure official scorer controls and rich real-time read-only spectator broadcast view.
- **Teams & Tournament Manager**: Squad selection, custom logos, player profile avatars, and draft recovery.
- **QR Code Syncing & Scanner**: Real-time cross-device sync and squad data sharing.
- **Automated APK Builds**: GitHub Actions workflow for building Android APKs on every push.
